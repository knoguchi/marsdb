# MarsDB 内部構造

> [English version](../internals/index.html)

この部は、これまでの章とは異なる読者を対象としています。前半で説明した
のが MarsDB の「使い方」だとすれば、ここで扱うのは「内部でどのように
動くのか」です。ディスク上のデータ配置、トランザクションの仕組み、
Cypher 文が解析されて結果行になるまでの流れ、そして各所の設計判断を
取り上げます。

グラフデータベースを理解したい、あるいは自分で実装したい開発者が、
MarsDB をひとつの完結したケーススタディとして読める構成です。MarsDB は、
数個のクレート、ひとつのストレージエンジン、ひとつのクエリパイプライン
という、全体像を把握できる規模に収まっています。それでも、ACID
トランザクション、クラッシュ耐性、セカンダリインデックス、コストを
考慮したプランナ、ストリーミング実行、3 種類の言語境界をまたぐ
ゼロコピーの結果受け渡しを備えた、実用的なデータベースです。本編で示す
性能値は、すべてこのリポジトリのベンチマークスイートによる実測値であり、
推定値ではありません。

## 章構成

1. [設計概要](./design-overview.md) — MarsDB とは何か、クレート構成、
   文が実行されるまでの流れ、トランザクションモデル。
2. [ストレージ層](./storage.md) — redb、13 のテーブル、トランザクション
   抽象、バックアップと整合性検査。
3. [グラフのエンコーディング](./graph-encoding.md) — 値モデル、
   インターニング、レコードのディレクトリ形式、隣接キー。
4. [書き込みパス](./write-path.md) — CRUD 層、テーブルハンドルの
   キャッシュ、ミューテーションの構造、不変条件の仕様としての
   整合性チェッカー。
5. [クエリフロントエンド](./query-frontend.md) — 文法、AST 設計、
   パラメータ、意味検証。
6. [IR とプランナ](./ir-and-planner.md) — 論理演算子、プッシュダウン、
   プロパティインデックス、インデックスシーク、コストベースの
   開始点選択、`EXPLAIN`。
7. [エグゼキュータ](./executor.md) — 実行計画の評価、実行制限、3 値論理、
   集約、ストリーミング実行経路。
8. [結果と言語境界](./results-and-boundaries.md) — 結果モデル、
   C ABI、ゼロコピー Arrow エクスポート。
9. [テストと計測](./testing-and-measurement.md) — TCK、クラッシュ
   ハーネス、ベンチマーク台帳。
10. [実測に基づくトレードオフのケーススタディ](./case-studies.md) —
    設計判断を支え、ときには覆した計測結果。
