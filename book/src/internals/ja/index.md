# MarsDB 内部構造

> [English version](../internals/index.html)

この部では、MarsDB の内部実装を説明します。対象は、データベースファイル内の
データ配置、トランザクション、Cypher の解析、実行計画の作成と評価、言語
バインディングへの結果の受け渡しです。

MarsDB は、複数の Rust クレート、redb を使ったストレージ層、ひとつのクエリ
処理系で構成されています。ACID トランザクション、クラッシュ耐性、セカンダリ
インデックス、コストに基づく開始点選択、ストリーミング実行、Arrow による
ゼロコピーの結果受け渡しを、実際のコードに沿って取り上げます。性能値は
リポジトリ内のベンチマークで測定したものです。

## ソースコードとの対応

各章には、説明対象のソースファイルを記載しています。ファイルパスはリポジトリ
ルートからの相対パスです（例: `marsdb-graph/src/store.rs`）。実装と説明が異なる
場合は、ソースコードの動作を基準とします。
