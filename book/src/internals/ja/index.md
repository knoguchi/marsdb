# MarsDB 内部構造

> English version is [here](../index.md).

この部は、ここまでの章とは異なる読者に向けて書かれています。前半の章が
MarsDB の「使い方」を説明するのに対し、この部は「どう動いているか」を
説明します — ディスク上のレイアウト、トランザクション機構、Cypher 文が
テキストから行になるまでの経路、そしてその途中にある設計判断の理由です。

グラフデータベースを理解したい、あるいは自分で作りたい開発者のために、
MarsDB を完結した読みやすいケーススタディとして使う構成になっています。
MarsDB は頭の中に収まる規模です — 数個のクレート、1 つのストレージ
エンジン、1 本のクエリパイプライン — しかし本物のデータベースでも
あります: ACID トランザクション、クラッシュ安全性、セカンダリ
インデックス、コストを考慮するプランナ、ストリーミング実行、そして
3 つの言語境界すべてでのゼロコピー結果。これらの章に登場する性能に
関する主張は、すべてこのリポジトリのベンチマークスイートで実測された
数値であり、推定値ではありません。

## 章構成

1. [設計概要](./design-overview.md) — MarsDB とは何か、クレート構成、
   文が実行されるまでの流れ、トランザクションモデル。
2. [ストレージ層](./storage.md) — redb、13 のテーブル、トランザクション
   抽象、バックアップと整合性検査。
3. [グラフのエンコーディング](./graph-encoding.md) — 値モデル、
   インターニング、レコードのディレクトリ形式、隣接キー。
4. [書き込みパス](./write-path.md) — CRUD 層、テーブルハンドルの
   キャッシュ、ミューテーションの構造、不変条件の仕様としての
   整合性チェッカー。
5. [クエリフロントエンド](./query-frontend.md) — 文法、AST 設計、
   パラメータ、意味検証。
6. [IR とプランナ](./ir-and-planner.md) — 論理演算子、プッシュダウン、
   プロパティインデックス、インデックスシーク、コストベースの
   開始点選択、`EXPLAIN`。
7. [エグゼキュータ](./executor.md) — プラン評価、実行制限、3 値論理、
   集約、ストリーミングレーン。
8. [結果と言語境界](./results-and-boundaries.md) — 結果モデル、
   C ABI、ゼロコピー Arrow エクスポート。
9. [テストと計測](./testing-and-measurement.md) — TCK、クラッシュ
   ハーネス、ベンチマーク台帳。
10. [実測に基づくトレードオフのケーススタディ](./case-studies.md) —
    設計判断を決めた(そして覆した)計測たち。
